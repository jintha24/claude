# Asset Register

Every third-party asset in the game must be listed here with its source and licence.
This keeps the game legally safe to sell on Steam or itch.io. The in-game credits
(Phase 9) are generated from this list.

**Allowed licences:** CC0, CC-BY 3.0/4.0 (credit required), and the Mixamo/Adobe terms
(royalty-free in games). **Not allowed:** CC-BY-NC (non-commercial), CC-BY-ND, "editorial use
only", or anything ripped from other games.

## Current status (Phase 1)

| Asset | Status |
|---|---|
| Street, buildings, lamps, props | Generated by code — no external assets |
| Surface textures | Procedural fallbacks generated by code (`procedural_textures.gd`); replace with the downloads below |
| Harry and all the people | Generated by `tools/characters/build_characters.py` into `assets/characters/generated/` from the **MakeHuman** data (CC0, © MakeHuman Community): base mesh, shape targets, game-engine skeleton and skin weights from MPFB2 (https://github.com/makehumancommunity/mpfb2), the high-poly eyes and eye texture from MakeHuman 1.x (https://github.com/makehumancommunity/makehuman). Clothes, hats, hair, beards and all their textures (skin, cloth, hair, eye colours) are made by the generator. A hand-made `assets/characters/harry/harry.glb` replaces Harry's generated body if added |
| Sky | Godot `PhysicalSkyMaterial` (built in) |
| Font | The player's system serif (Georgia / Times New Roman); a licensed Victorian font comes in Phase 9 |

## Where each kind of asset goes

| Type | Source | Licence | Project folder |
|---|---|---|---|
| Ground/wall/roof textures | https://polyhaven.com/textures · https://ambientcg.com | CC0 | `assets/textures/<material>/` (see PHASE_1_GUIDE Part 5) |
| HDRI skies (optional, Phase 5) | https://polyhaven.com/hdris | CC0 | `assets/hdri/` |
| Props (barrels, carts, lamps) | https://polyhaven.com/models · https://sketchfab.com (filter: Downloadable + CC-BY/CC0) | CC0 / CC-BY | `assets/models/props/<name>/<name>.glb` |
| Human characters | MPFB / MakeHuman (https://static.makehumancommunity.org/mpfb.html) | CC0 for generated bodies; check each clothing asset | `assets/characters/<name>/<name>.glb` |
| Character animations | https://www.mixamo.com | Adobe Mixamo terms (royalty-free) | combined into the character `.glb` (PHASE_1_GUIDE Part 6) |
| Sounds | https://freesound.org (filter: CC0 or Attribution) | CC0 / CC-BY | `assets/audio/<category>/` |
