# Getting the *Assassin's Creed Syndicate* Look

The look you're after (sunlit Victorian London in a soft blue haze, pale classical stone,
ornate street furniture, and detailed, realistic people) comes from two very different
things:

1. **The world's mood**: light, sky, haze, architecture, street dressing, skyline. **Most
   of this is done in code already** and gets better as real textures are added.
2. **The characters and hero assets**: Harry's face and coat, the townsfolk, the carved
   stonework. At Syndicate's level these are **hand-made 3D art** (scanned faces,
   sculpted clothes, 4K textures) produced by an art team of hundreds. **No code can
   generate that.** You have to get the models (buy, download or commission them) and drop
   them in. The game is built so each one plugs in without code changes.

This guide covers both, in order of how much each step improves the picture.

---

## Part 1 — What the game already does (the visual pass)

| What | Where |
|---|---|
| Bright blue physical sky with fair-weather cumulus (white tops, blue-grey bellies) | `scenes/main/london_environment.tres`, `scripts/world/weather_effects.gd` |
| Blue-grey aerial haze over distance, warm sun scatter, volumetric light shafts | the Environment's fog settings, `scripts/world/day_night_cycle.gd` |
| Distant London: about 4,500 terraces with chimney stacks, **St Paul's**, the **Palace of Westminster** (Clock Tower 1859, Victoria Tower 1860), Wren and Hawksmoor spires, and factory chimneys trailing smoke | `scripts/world/london_skyline.gd` |
| Ornate gas lamps: fluted columns, gilt collars, scrollwork, **hanging flower baskets** | `scripts/world/gas_lamp.gd` (`flower_baskets`) |
| London plane and lime trees with leaves that sway in the wind; cast-iron bollards | `StreetProps.make_tree()`, `make_bollard()` |
| A Greek Revival **columned bank front** closing the street | `LondonStreet._build_bank_portico()` |
| Ashcombe House dressed in pale stone: quoins, architraves, pediments, balustrade and urns | `AshcombeHouse._dress_facades()` |
| Cleaner Portland stone and stucco (less grime in the stand-in textures) | `scripts/world/procedural_textures.gd` |
| Harry's silhouette: a long, flared brown leather greatcoat, top hat with a red band, belt and buckle, gloves, riding boots, shoulder guard | `scripts/player/harry_mannequin.gd` |

**Use the Forward+ renderer on your PC** (the default in `project.godot`). SDFGI, volumetric
fog, SSR and SSIL, which make the light look real, only exist there. The "Compatibility"
renderer is much flatter.

## Part 2 — Real textures (big improvement, free, 1 hour)

The stand-in textures are generated by code. Real photo-scanned materials make the biggest
single difference to walls, roads and stone.

1. Go to **https://polyhaven.com/textures** (CC0, free for any use) or **https://ambientcg.com** (CC0).
2. Download at **2K**, JPG or PNG, and unzip each one into the matching folder:

| Folder in `assets/textures/` | Search for |
|---|---|
| `brick_yellow` | "yellow brick" / "London stock brick" |
| `brick_red` | "red brick" |
| `stucco` | "plaster" / "painted plaster" (cream) |
| `stone_trim` | "Portland stone" / "limestone" / "sandstone blocks" |
| `cobblestone` | "cobblestone" / "setts" |
| `pavement` | "paving slabs" / "flagstones" |
| `slate_roof` | "roof slates" |
| `wood_planks`, `floorboards` | "wood planks" / "floor boards" |
| `marble` | "marble floor" |
| `grass`, `gravel` | "grass" / "gravel" |

3. Start the game. `MaterialLibrary` finds them automatically (no renaming needed).

## Part 3 — A real sky (10 minutes)

For Syndicate-style clouds, use a photographed sky:
1. Download a daytime **HDRI** from **https://polyhaven.com/hdris**, such as "kloofendal_48d_partly_cloudy" or any "partly cloudy" sky. Take the 4K `.exr` file.
2. Put it in `assets/hdri/`. In `scenes/main/london_environment.tres` → **Sky → Sky Material**, choose **New PanoramaSkyMaterial**, then drag the HDRI onto **Panorama**.
3. The day/night script only adjusts the physical sky, so keep the original too if you want nights. A mixed setup (HDRI by day) arrives with the Phase 10 art pass.

## Part 4 — Realistic characters (the biggest step, and it's art, not code)

Harry and every NPC already have a **model slot**:
- **Harry:** `assets/characters/harry/harry.glb`, which is loaded automatically. See **PHASE_1_GUIDE, Part 6**.
- **NPCs:** the `body_model_path` property on any NPC. Outfit-specific models arrive in Phase 10.

Ways to get Syndicate-quality people, from best to cheapest:

| Tool / source | Quality | Cost and licence (check the current terms before buying) | Notes |
|---|---|---|---|
| **Reallusion Character Creator 4** + **Headshot** plug-in | Very high: realistic skin, face from a photo, hair | Paid. Its licence allows use in games | Victorian clothing packs are in the Reallusion Content Store. Export FBX → **Mixamo** or CC's own rig → Blender → `.glb`. |
| **Marvelous Designer** | The long leather coat and waistcoat as real sewn cloth | Paid (subscription) | Export the garment and bake it onto the CC4 or MPFB body in Blender. |
| **Sketchfab** (filter: Downloadable, CC-BY or CC0, "victorian man / woman") | Varies from good to very good | Free or paid, per model | Record the licence and author in `docs/ASSETS.md`. |
| **Blender + MPFB (MakeHuman)** + community clothes | Medium | Free (CC0 / CC-BY assets) | The route already written up in PHASE_1_GUIDE, Part 6. |
| **Commission an artist** (ArtStation, Fiverr) | Anything you can pay for | Paid; get the commercial rights in writing | Brief them: "1866 London, 6'2" male, 26, long weathered leather greatcoat, top hat, ready for Mixamo rigging, under 60k triangles, 4K PBR textures". |

**Not allowed:** Epic's **MetaHumans** may only be used in Unreal Engine projects, and models
ripped from other games (Syndicate included) are copyrighted. Don't use either.

**Animations:** Mixamo (free) covers walking, running, climbing, sneaking and fighting.
Motion-capture packs from the Unity or Unreal marketplaces usually allow use in any engine
(read each pack's licence).

**Performance budget per character** (for a crowd of 50+): hero (Harry) up to 60k triangles
with 4K textures; townsfolk 15–25k with 2K textures, using Godot's automatic LOD (on by
default for imported meshes).

## Part 5 — Hero buildings (optional, later)

The street's buildings are built by code so they're always the right size for climbing.
To get Syndicate-level carving (Corinthian capitals, carved cornices), model a few
**kit pieces** in Blender, or buy a "Victorian / Georgian architecture modular kit". You need:
- a window surround
- a cornice section
- a column capital
- a door case

Swap them in for the boxes in `BuildingFacade` (Phase 10 adds a slot for kit pieces).
Keep collision as the simple boxes, so climbing stays reliable.

## Part 6 — Settings for the best image

- **Project Settings → Rendering → Anti Aliasing:** TAA on (already set). On a slower GPU,
  set **Rendering → Scaling 3D → Mode: FSR 2** with **Scale 0.77** (Phase 9's graphics menu
  offers this as a preset).
- **Environment:**
  - SDFGI on, with *Use Occlusion*.
  - Volumetric fog on.
  - Glow on.
  - Tonemap: AgX.
  - Exposure: auto (the Camera Attributes resource).

  All of these are already set.
- **Recommended PC** for this look: RTX 3060 / RX 6700 or better, 16 GB RAM.
