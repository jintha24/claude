THE THIEF OF LONDON
===================

London, 1866. You are Harry Crane, "The Hill Fox": take from those who won't miss it,
give to those who can't live without it.


SYSTEM REQUIREMENTS
-------------------
Minimum:     Windows 10 64-bit, 4-core CPU, 8 GB RAM,
             GTX 1060 / RX 580 class graphics card (Vulkan 1.2 or Direct3D 12),
             4 GB disk space.
             Use the Low graphics preset.
Recommended: Windows 11 64-bit, 6-core CPU, 16 GB RAM,
             RTX 3060 / RX 6600 class graphics card, SSD.


CONTROLS (keyboard and mouse; a controller works too)
-----------------------------------------------------
Move                 W A S D
Look                 Mouse
Sprint / Walk        Shift / Ctrl
Crouch               C
Jump, climb, vault   Space
Use, talk, pick      E
Aim / loose arrow    Right mouse / Left mouse
Change arrows        R
Horse: mount         F
Whistle for Cinder   H
Ledger (pocket-book) Tab (hold)
Pause menu           Esc
Performance overlay  F3
Every key can be changed in Settings > Controls.


SAVED GAMES
-----------
The game autosaves when you sleep (the cave, the crypt) and when you travel between
London and the hills. Save by hand from the pause menu (5 slots).
Saves and settings are in:  %APPDATA%\ThiefOfLondon


IF THE GAME WON'T START OR RUNS BADLY
-------------------------------------
1. Update your graphics driver (NVIDIA, AMD or Intel website).
2. Try the "safe mode" shortcut in the Start menu. It uses Direct3D 12 instead of
   Vulkan.
3. In Settings > Graphics choose Low, or turn off Volumetric fog.
4. Run TheThiefOfLondon.console.exe to see error messages in a terminal window.
